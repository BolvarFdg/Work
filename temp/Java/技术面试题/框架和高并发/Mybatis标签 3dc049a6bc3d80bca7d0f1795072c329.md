# Mybatis标签

MyBatis XML标签（面试版，分4大类）

一、CRUD基础标签（Mapper顶级）

1. <select>：查询语句，属性：id、resultType / resultMap、parameterType
2. <insert>：新增；<selectKey>写在里面，用于获取自增主键
3. <update>：更新
4. <delete>：删除

二、结果映射 & 缓存 & SQL片段

1. <resultMap>：核心，数据库字段和Java实体属性映射；支持一对一<association>、一对多<collection>

◦ id：主键映射

◦ result：普通字段映射

1. <sql>：定义可复用SQL片段
2. <include refid="">：引用<sql>片段
3. <cache>：当前namespace二级缓存
4. <cache-ref>：引用其他命名空间的二级缓存
parameterMap：已废弃，不推荐使用
三、动态SQL标签（面试高频）
5. <if test="条件">：条件成立才拼接SQL，test用OGNL表达式
<if test="name != null"> AND name=#{name}</if>
6. <choose> <when> <otherwise>：类似switch，只会匹配一个分支
7. <where>：自动添加WHERE，自动去掉开头多余AND / OR
8. <set>：update专用，自动添加SET，自动删除末尾多余逗号
9. <trim>：通用自定义标签，prefix、suffix、prefixOverrides、suffixOverrides。where/set底层就是trim
10. <foreach>：遍历集合，常用于in、批量插入

◦ collection：集合名；item：单项；open/close；separator分隔符

1. <bind>：绑定变量，常用like模糊查询，避免数据库驱动差异
<bind name="likeName" value="'%' + name + '%'"/>
四、mybatis-config.xml 全局配置标签（根标签configuration）

顺序不能乱：
<properties>、<settings>、<typeAliases>、<typeHandlers>、<objectFactory>、<plugins>、<environments>、<databaseIdProvider>、<mappers>

面试常问

Q：where标签原理？
底层是trim，只会在内部有SQL片段时生成where；自动剔除第一个and/or。
Q：trim四个属性？
prefix前缀，suffix后缀，prefixOverrides要删掉的前缀，suffixOverrides要删掉的后缀。

Q：foreach属性？
collection、item、index、open、close、separator。
