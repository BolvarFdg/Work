# Lambda 表达式

Java 的 **Lambda 表达式**是 Java 8 引入的一项重要特性，用于简化函数式编程的实现。它的核心目的是以更简洁的方式表示匿名函数（即没有名称的函数），从而替代需要匿名内部类的场景，使代码更加简洁、易读。

---

### **Lambda 表达式的核心概念**

1. **语法形式**
    
    Lambda 表达式的基本语法如下：
    
    ```java
    (参数列表) -> { 方法体 }
    
    ```
    
    - **参数列表**：可以是空参数、单个参数或多个参数，类型可以显式声明或由编译器推断。
    - **箭头符号 `>`**：分隔参数和方法体。
    - **方法体**：可以是单行代码（无需 `{}` 和 `return`）或多行代码（需要 `{}` 和 `return`）。
    
    **示例**：
    
    ```java
    // 无参数
    () -> System.out.println("Hello");
    
    // 单参数，类型可推断
    s -> s.length();
    
    // 多参数
    (a, b) -> a + b;
    
    // 多行代码
    (x, y) -> {
        int sum = x + y;
        return sum * 2;
    };
    
    ```
    
2. **依赖函数式接口**
    
    Lambda 表达式必须实现一个**函数式接口**（Functional Interface），即仅包含一个抽象方法的接口。例如：
    
    - `Runnable` → `void run()`
    - `Comparator<T>` → `int compare(T o1, T o2)`
    - 自定义接口如 `@FunctionalInterface interface MyInterface { void doSomething(); }`

---

### **为什么需要 Lambda 表达式？**

1. **替代匿名内部类**
    
    传统方式需要冗长的匿名类实现，而 Lambda 表达式可以大幅简化代码。
    
    **示例：用 Lambda 实现 `Runnable`**
    
    ```java
    // 传统匿名内部类
    new Thread(new Runnable() {
        @Override
        public void run() {
            System.out.println("Running!");
        }
    }).start();
    
    // 使用 Lambda
    new Thread(() -> System.out.println("Running!")).start();
    
    ```
    
2. **支持函数式编程**
    
    结合 `Stream API` 处理集合数据时，Lambda 可以实现更声明式的代码风格：
    
    ```java
    List<Integer> numbers = Arrays.asList(1, 2, 3);
    numbers.stream()
           .filter(n -> n % 2 == 0)  // 过滤偶数
           .map(n -> n * 2)          // 每个元素乘以2
           .forEach(System.out::println); // 输出结果
    
    ```
    
3. **简化代码，提升可读性**
    
    尤其在处理回调、事件处理器时，代码更紧凑。
    

---

### **常见函数式接口**

Java 内置了一些常用的函数式接口（位于 `java.util.function` 包）：

- `Consumer<T>`：接受一个参数，无返回值 → `void accept(T t)`
- `Supplier<T>`：无参数，返回一个值 → `T get()`
- `Function<T, R>`：接受一个参数，返回结果 → `R apply(T t)`
- `Predicate<T>`：接受一个参数，返回布尔值 → `boolean test(T t)`

**示例**：

```java
Consumer<String> printer = s -> System.out.println(s);
printer.accept("Hello World"); // 输出 Hello World

Predicate<Integer> isEven = n -> n % 2 == 0;
System.out.println(isEven.test(4)); // 输出 true

```

---

### **Lambda 的变量捕获**

Lambda 可以访问外部的局部变量，但要求变量是 `final` 或“事实上不可变”（即未被修改）：

```java
int factor = 2; // 必须是 final 或事实上不可变
Function<Integer, Integer> multiplier = n -> n * factor;

```

---

### **方法引用**

Lambda 的进一步简化写法，用于直接调用已有方法：

- **静态方法引用**：`ClassName::staticMethod`
- **实例方法引用**：`instance::method`
- **构造方法引用**：`ClassName::new`

**示例**：

```java
List<String> names = Arrays.asList("Alice", "Bob");
names.forEach(System.out::println); // 等效于 s -> System.out.println(s)

```

---

### **总结**

- **Lambda 表达式**是 Java 函数式编程的核心工具，用于替代匿名内部类。
- 语法简洁，依赖**函数式接口**。
- 广泛用于集合处理（`Stream API`）、事件回调等场景。
- 结合方法引用可以进一步简化代码。

## Lambda表达式应用场景

Java 的 Lambda 表达式在多种场景中都能显著简化代码，提升可读性和灵活性。以下是其主要应用场景及示例：

---

### **1. 替代匿名内部类**

Lambda 表达式可以替代需要匿名内部类的场景（如 `Runnable`、`Comparator`、`事件监听`等），大幅减少模板代码。

**示例：多线程中的 `Runnable`**

```java
// 传统匿名内部类
new Thread(new Runnable() {
    @Override
    public void run() {
        System.out.println("Thread is running!");
    }
}).start();

// 使用 Lambda 表达式
new Thread(() -> System.out.println("Thread is running!")).start();

```

**示例：排序中的 `Comparator`**

```java
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");

// 传统匿名内部类
names.sort(new Comparator<String>() {
    @Override
    public int compare(String a, String b) {
        return a.length() - b.length();
    }
});

// 使用 Lambda 表达式
names.sort((a, b) -> a.length() - b.length());

```

---

### **2. 集合操作（结合 Stream API）**

Lambda 表达式与 `Stream API` 结合，可以高效处理集合数据，实现声明式编程（如过滤、映射、聚合等）。

**示例：过滤、映射和遍历**

```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

// 过滤偶数 → 每个元素乘以2 → 打印结果
numbers.stream()
       .filter(n -> n % 2 == 0)    // 过滤偶数
       .map(n -> n * 2)            // 映射为原值的2倍
       .forEach(System.out::println); // 输出：4, 8

```

**示例：聚合操作**

```java
List<String> words = Arrays.asList("Java", "Python", "C++");

// 计算所有单词的总长度
int totalLength = words.stream()
                       .mapToInt(s -> s.length())
                       .sum();
System.out.println(totalLength); // 输出：11 (4+6+3)

```

---

### **3. 函数式接口作为方法参数**

Lambda 表达式可以作为参数传递给接受函数式接口的方法，实现灵活的行为传递。

**示例：自定义回调函数**

```java
@FunctionalInterface
interface Callback {
    void execute(String message);
}

class Processor {
    public void process(String input, Callback callback) {
        System.out.println("Processing: " + input);
        callback.execute("Done!");
    }
}

// 使用 Lambda 传递回调逻辑
Processor processor = new Processor();
processor.process("Hello", msg -> System.out.println("Result: " + msg));
// 输出：
// Processing: Hello
// Result: Done!

```

---

### **4. 事件监听（如 GUI 开发）**

在图形界面开发中（如 JavaFX 或 Swing），Lambda 表达式简化事件监听器的实现。

**示例：按钮点击事件**

```java
// JavaFX 或 Swing 中的按钮点击事件
button.setOnAction(event -> System.out.println("Button clicked!"));

```

---

### **5. 延迟执行（Lazy Evaluation）**

结合 `Supplier` 等函数式接口，Lambda 可以用于延迟计算，仅在需要时执行逻辑。

**示例：按需生成日志**

```java
public void log(Supplier<String> messageSupplier) {
    if (isDebugEnabled()) {
        System.out.println(messageSupplier.get()); // 仅在调试模式下执行
    }
}

// 使用 Lambda 延迟拼接日志内容
log(() -> "Debug info: " + expensiveOperation());

```

---

### **6. 并行处理**

结合 `parallelStream()`，Lambda 表达式可以轻松实现并行计算，提升多核 CPU 利用率。

**示例：并行计算平方和**

```java
List<Integer> nums = Arrays.asList(1, 2, 3, 4, 5);
int sumOfSquares = nums.parallelStream()
                       .mapToInt(n -> n * n)
                       .sum();
System.out.println(sumOfSquares); // 输出：55 (1+4+9+16+25)

```

---

### **7. 方法引用（进一步简化 Lambda）**

Lambda 表达式可替换为方法引用（`Class::method`），提升代码简洁性。

**示例：方法引用遍历集合**

```java
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
names.forEach(System.out::println); // 等效于 s -> System.out.println(s)

```

---

### **总结：Lambda 的核心应用场景**

| **场景** | **示例** | **优势** |
| --- | --- | --- |
| 替代匿名内部类 | `Runnable`、`Comparator` | 代码简洁，减少模板代码 |
| 集合操作（Stream API） | 过滤、映射、聚合 | 声明式编程，易于维护 |
| 函数式接口参数 | 自定义回调、工具类方法 | 灵活传递行为逻辑 |
| 事件监听 | GUI 按钮点击事件 | 简化事件处理代码 |
| 延迟执行 | 日志记录、按需计算 | 优化性能，避免不必要的 |
