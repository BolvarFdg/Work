# JVM内存溢出定位

**1. 打印栈信息**

- jstack pid: 打印堆栈信息
- jstat -gcutil pid: 查看gc信息和频率

**2. 获取dump文件**

   `jmap -dump:live,format=b,file=/home/myheapdump.hprof 应用进程ID`

**3. 分析dump文件**

     使用工具加载 hprof 文件

**JVM 常用命令**

- jstat：获取JVM运行状态信息
- jps：获取所有Java进程的pid和名称
- jstack：生成虚拟机当前线程快照
- jmap：生成堆快照
- jconsole：监视 jvm 的各种运行时信息
- jvisualvm：图形化工具，分析内存信息

**JVM 内存分析工具**

- VisualVM：jdk自带工具
- JProfiler
- MAT
- Eclipse Memory Analyze

**常用参数：**
1、-Xms：初始化堆大小
2、-Xmx：最大堆大小
3、-Xmn：新生代的内存空间大小
4、-XX：SurvivorRatio
5、-Xss：每个线程的堆栈大小
6、-XX：PermSize：设置永久代初始值
7、- XX：MaxPermSize：设置永久代最大值
